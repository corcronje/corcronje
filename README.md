### I solve problems. I build things that work. I deliver.

Since **2001**, I have built production systems from the ground up — from physically installing network infrastructure and soldering circuit boards to architecting enterprise applications and deploying intelligent software.

When I say **full stack**, I mean the entire technology spectrum:

```
Hardware → Firmware → Networks → Servers → Databases → Backend → Web → Mobile
```

I leverage modern **AI tools**, coding assistants, and agentic workflows to move faster and deliver more — without cutting corners. The technology has changed, but the fundamentals haven't: understand the problem, design the solution, execute with precision, and ship something that actually works in the real world.
